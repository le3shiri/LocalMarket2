# Definition of Done

## Backlog item
- [ ] Acceptance criteria are met.
- [ ] Code is merged into `develop` through a reviewed branch.
- [ ] Authorization (role) and server-side validation are in place.
- [ ] Relevant automated tests exist and `php artisan test` passes.
- [ ] Code style passes (`vendor/bin/pint --test`).
- [ ] Documentation (requirements status, diagrams, user manual) is updated.
- [ ] No known critical bug remains.
- [ ] The other developer reviewed the change.
- [ ] The feature can be demonstrated with seed data.

## Sprint
- [ ] All "done" items demonstrated in the sprint review.
- [ ] Sprint branch committed, pushed to GitHub and merged (or the push blocker is documented).
- [ ] Sprint tagged (`sprint-N`).
- [ ] `PROJECT_STATUS.md`, `PRODUCT_BACKLOG.md` and the sprint report are updated.
- [ ] Incomplete items are moved back to the backlog with notes.
