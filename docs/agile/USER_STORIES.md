# User Stories

Format: *As a ‹role›, I want ‹goal› so that ‹benefit›.* Acceptance criteria are in `ACCEPTANCE_CRITERIA.md`.

| ID | Story | Req. | Points |
|---|---|---|---|
| US-01 | As a customer, I want to register and log in so that I can place and follow orders. | FR-AUTH-01/02 | 3 |
| US-02 | As any user, I want to reset my password by email so that I can recover my account. | FR-AUTH-04 | 2 |
| US-03 | As an admin, I want each role to see only its allowed pages so that data is protected. | FR-AUTH-06 | 3 |
| US-04 | As a customer, I want to browse and search products by category so that I find what I need. | FR-CAT-03 | 3 |
| US-05 | As a customer, I want to see product details and availability so that I know if I can buy it. | FR-CAT-04 | 2 |
| US-06 | As an admin, I want to manage products and categories so that the catalogue is correct. | FR-CAT-05/06 | 5 |
| US-07 | As a warehouse tech, I want to record receipts with lot and expiry so that stock is accurate. | FR-INV-02/04 | 5 |
| US-08 | As a warehouse tech, I want to transfer stock between warehouse and store so that the store is replenished. | FR-INV-02 | 3 |
| US-09 | As a warehouse tech, I want to adjust stock with a reason so that counts match reality. | FR-INV-02/03 | 2 |
| US-10 | As staff, I want to see stock by location and movement history so that I can trace changes. | FR-INV-01/09 | 3 |
| US-11 | As a warehouse tech, I want alerts for low stock and near expiry so that I act in time. | FR-INV-08 | 2 |
| US-12 | As a customer, I want a cart so that I can collect products before paying. | FR-ORD-01 | 3 |
| US-13 | As a customer, I want to check out choosing delivery or pickup so that I get my order my way. | FR-ORD-02, FR-DEL-01/02 | 5 |
| US-14 | As the business, I want stock reserved at checkout so that we never oversell. | FR-INV-05/06/07 | 5 |
| US-15 | As a customer, I want to pay by card securely so that my order is confirmed. | FR-PAY-01..05 | 8 |
| US-16 | As a customer, I want to see my orders and their status so that I know what is happening. | FR-ORD-06 | 2 |
| US-17 | As a cashier, I want to move orders through preparation, pickup/delivery and completion. | FR-ORD-04/05/07 | 3 |
| US-18 | As an admin, I want to cancel orders (with refund if paid) so that problems are handled. | FR-PAY-06, BR-ORD-04 | 3 |
| US-19 | As a customer, I want email updates about my order so that I don't have to check the site. | FR-NOT-01/02 | 3 |
| US-20 | As an admin, I want to create coupons with rules so that I can run promotions. | FR-PRO-01..03 | 5 |
| US-21 | As an admin, I want to manage employee and customer accounts so that access is controlled. | FR-USR-01/02, FR-AUTH-05/07 | 3 |
| US-22 | As an admin, I want an audit log so that I know who changed what. | FR-AUD-01/02 | 3 |
| US-23 | As the business, I want unpaid orders to expire so that reserved stock returns. | FR-ORD-08 | 2 |
| US-24 | As a cashier, I want to record in-store sales so that online stock stays correct. *(pending approval)* | FR-POS-01 | 2 |
