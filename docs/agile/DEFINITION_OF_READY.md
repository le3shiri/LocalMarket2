# Definition of Ready

A backlog item can enter a sprint when:

- [ ] It is written as a user story with a clear role, goal and benefit.
- [ ] Acceptance criteria are written and testable.
- [ ] It is linked to a requirement ID (FR/NFR/BR).
- [ ] Business rules and open questions affecting it are answered or have an approved default.
- [ ] It is estimated (story points) and small enough for one sprint (≤ 8 points).
- [ ] Dependencies are known (other stories, credentials, data).
- [ ] UI sketch or page list exists if it has a user interface.
- [ ] An owner (Developer A or B) and a reviewer are named.
